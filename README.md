# TaxBox - Solution SaaS de Gestion Fiscale pour Cabinets Comptables Marocains

## 📋 Description
TaxBox est une plateforme SaaS conçue pour simplifier la gestion des déclarations fiscales (IS, IR, TVA) pour les cabinets comptables marocains.

## 🎯 Fonctionnalités principales
- **Gestion des clients/dossiers** : Organisez vos clients et leurs dossiers fiscaux
- **Déclarations fiscales** : Formulaires pour IS, IR, TVA avec calculs automatiques
- **Génération de rapports** : Export PDF des déclarations
- **Dashboard analytique** : Statistiques et suivi des dossiers
- **Gestion d'équipe** : Rôles et permissions pour les utilisateurs du cabinet
- **Historique** : Archivage et version control des déclarations

## 🏗️ Architecture

```
TaxBox/
├── frontend/          # Application Next.js
├── backend/           # API Node.js/Express
├── docs/              # Documentation
└── scripts/           # Utilitaires
```

## 🚀 Stack technologique
- **Frontend** : Next.js 14 + TypeScript + Tailwind CSS
- **Backend** : Node.js + Express + TypeScript
- **Base de données** : PostgreSQL
- **ORM** : Prisma
- **Auth** : JWT + bcrypt
